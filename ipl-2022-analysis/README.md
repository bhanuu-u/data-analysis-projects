# 🏏 IPL 2022 Data Analysis

A Python-based data analysis project exploring IPL 2022 match data using Pandas, Matplotlib, and Seaborn.

## 📌 Project Overview

The Indian Premier League (IPL) generates a large amount of data related to teams, players, matches, tosses, venues, and match results.

In this project, I analyzed IPL 2022 match data to answer different cricket-related questions and identify useful patterns and insights.

The project contains **11 analytical questions**, covering team performance, toss trends, player performance, bowling performance, venues, and match margins.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
