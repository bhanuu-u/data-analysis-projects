# 🏏 IPL 2025 Analysis

A data analysis and visualization project exploring the **Indian Premier League (IPL) 2025** using Python, Pandas, Matplotlib, and Seaborn.

The project analyzes team performance, toss decisions, match outcomes, batting performance, strike rates, scoring patterns, and innings phases using ball-by-ball IPL data.

---

## 🎯 Project Objective

The objective of this project is to explore IPL 2025 data and answer meaningful cricket-related questions using data analysis and visualization.

Instead of only looking at basic statistics, the project focuses on identifying patterns in:

- Team wins
- Toss decisions
- Toss impact on match results
- Winning methods
- Batting performance
- Runs vs. strike rate
- Runs scored across overs
- Powerplay, middle overs, and death overs

---

## 🛠️ Technologies Used

- **Python**
- **Pandas**
- **Matplotlib**
- **Seaborn**
